# plans — 実行計画

計画は第一級の成果物。数セッションに跨る作業は、着手前に `active/<slug>.md` を作り、進捗と途中の決定をそこに追記する。会話ログには残さない。
完了したら `completed/` へ移動し、`../handoff.md` の参照を外す。`harness gc` は `active/` で長期間更新のない計画を報告する。

軽い変更（1 セッションで終わる）には計画を作らない。`handoff.md` の NEXT で足りる。

## テンプレート（`active/<slug>.md`）

```markdown
# <タイトル>

- 開始: YYYY-MM-DD
- 状態: 計画中 / 進行中 / ブロック中 / 完了
- 関連: docs/decisions/NNNN, spec/...

## 目的（何ができれば完了か）

## 受け入れ条件（検査で確認できる形に）

- [ ] `harness check` の X が通る
- [ ] ...

## タスク分解（依存順）

| # | タスク | 状態 | 備考 |
|---|---|---|---|

## 決定ログ（日付・決めたこと・理由・落選案）

## 進捗ログ（セッションごとに 1〜3 行）

## 未確定事項（人間の判断待ち）
```
